# React Router Multipage Website 🌐

This is a responsive multi-page website built using **React.js** and **React Router DOM**. It includes routing between pages and features a clean, modern UI. The site supports **Login and Signup validations** using JavaScript.

## 🚀 Features

- ⚛️ Built with React
- 🔁 Navigation using React Router
- 📱 Fully responsive design
- 🔒 Login and Signup form validation
- ✨ Smooth UI with clean layout
- 📁 Modular component structure

## 🛠️ Tech Stack

- React JS
- React Router DOM
- JavaScript
- HTML5 & CSS3
